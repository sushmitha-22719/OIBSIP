# Calculator

## About the Project

This project is a simple and responsive calculator developed using HTML, CSS, and JavaScript.

It performs basic arithmetic operations and provides a clean and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear button
- Backspace button
- Operator chaining
- Division-by-zero error handling
- Responsive calculator layout
- Interactive button effects
