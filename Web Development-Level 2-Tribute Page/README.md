# Tribute Page – Lord Shiva

## About the Project

This project is a tribute page dedicated to Lord Shiva.

The page presents information about Lord Shiva, his qualities, important aspects, and his significance in Hindu tradition.

## Technologies Used

- HTML5
- CSS3

## Features

- Lord Shiva title and tagline
- Nataraja image
- About Lord Shiva section
- Important aspects section
- Quote section
- Responsive design
- Clean and simple layout
- Multiple background colors
- Different font styles
