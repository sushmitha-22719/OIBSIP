# To-Do Web App

## About the Project

This project is a simple and responsive To-Do Web App developed using HTML, CSS, and JavaScript.

It helps users add, complete, edit, and delete tasks while keeping track of pending and completed tasks.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Edit tasks
- Delete tasks
- Pending task count
- Completed task count
- Empty-state messages
- Responsive design
- Enter key support for adding tasks
